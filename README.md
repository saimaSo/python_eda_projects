# Python EDA Projects

A collection of exploratory data analysis (EDA) projects in Python, using Pandas, NumPy, Matplotlib and Seaborn, completed during my Data Analytics course at PW Skills.

## Projects

### 1. Travel Customers EDA

Explored a travel customer dataset to understand customer profiles and behavior.

- Cleaned the data by fixing an inconsistent value in the Gender column and removing rows with missing values.
- Performed univariate analysis on categorical and numerical columns using count plots and histograms.
- Found that the 30 to 40 age group travels the most, and that most customers came through self-inquiry.

### 2. Student Performance EDA

Explored a student performance dataset covering student background, family and lifestyle.

- Checked the dataset for missing values and summarized key columns.
- Analyzed age, school, home area, reason for choosing the school, activities and parents' education using charts.
- Found that most students are 16 to 17 years old and come from urban areas.
- Detected outliers in age and absences using the IQR method.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
